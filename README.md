# Aly画布

在画布里组织文字、图片、视频和音频，连接素材创作，使用多轨整理片段。

当前版本：**v0.8.4 · Windows x64 正式版**。

- [版本说明](https://github.com/HunterAyi/Aly-Canvas/releases/tag/v0.8.4)
- [软件主页](https://www.aly18.com)

已有版本可从软件版本号旁的绿色更新提醒下载。本次只更新核心，约 317.6 MiB，兼容模型和环境继续使用。保存工程并处理活动任务后，再按提示退出安装。

首次安装双击 Setup，选择安装位置。基础组件约 738 MiB；本地抠图模型和CPU环境约 1.77 GiB，首次使用并确认后安装。无需预装系统 Python 或 CUDA。在线生成服务需要自行配置供应商与 KEY。

本版修复更新完成提示、多轨末尾重播和抠图快速返回的保存冲突，并加强退出时的活动任务检查。工程、素材、KEY、偏好、小A会话和个人知识保留。

目前支持 Windows x64；此前测试机为 Win10、16GB、RTX2080，本次候选在开发电脑完成成品验收。没有 Mac 版本，也未覆盖所有硬件组合。未购买 Windows 发布者代码签名，浏览器或系统可能提示下载信誉不足或未知发布者；无需关闭系统整体防护。SHA256和组件签名不等同于发布者认证。
