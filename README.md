# Aly画布

在本机画布中组织图片、视频、文字和参考素材，连接你自己的模型服务，继续编辑、抠图与多轨剪辑。

当前版本 **v0.8.0 · 首次公开测试版**，面向 Windows x64。第一次公开测试，欢迎下载安装并反馈具体问题。

[下载安装包与版本说明](https://github.com/HunterAyi/Aly-Canvas/releases/tag/v0.8.0)

## 开始使用

1. 下载 `AlyCanvas-0.8.0-Windows-x64-Setup.zip`，解压到一个文件夹，运行其中的 `AlyCanvasInstaller.exe`。
2. 选择安装位置。安装器会下载并校验画布、小A和音视频基础组件；不要只取出一个 EXE 单独运行。
3. 从桌面 **Aly画布** 进入首页，新建画布或打开工程。在 API 设置中填入自己的连接与 KEY。
4. 基础组件约771 MB；本地抠图额外约1.90 GB。第一次打开本地抠图时，会显示模型和 CPU 环境的下载大小；点击安装后才下载，画布可以继续使用。安装完成后，本地抠图可离线使用。

首页、画布和 API 设置共享主题。工程自动保存在本安装目录的用户资料中；重要作品也可以导出备份。

## 这版可以做什么

- 在画布上组织文字、图片、视频与音频，使用编组、参考连线和素材库。
- 配置图片与视频模型，按模型支持的方式使用参考素材。
- 使用图片裁剪、旋转、标注、本地抠图及多轨剪辑。
- 使用小A协助处理软件操作、配置资料和用户知识。

在线生成及小A需要相应服务与权限，服务商可能收费。具体可用模型、能力、价格和网络表现以对应供应商为准。

## 更新与退出

有新版本时，首页和 API 页的版本号旁会显示绿色小灯泡与更新提醒。点击查看版本说明及本次下载大小，再决定是否下载。

兼容组件会继续使用；软件正常保存并退出后，在原安装位置更新。更新失败会保留恢复材料，工程、KEY、设置和会话不会随程序更新被重置。

关闭网页后，画布仍在系统托盘运行。点击托盘或桌面入口可以重新打开；需要完全退出时，在托盘右键选择退出。有活动任务或未保存内容时，软件会说明阻塞原因。
