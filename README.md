# Aly画布

把文字、图片、视频和音频放在同一张画布上，连接参考素材，完成生成、图片处理和多轨剪辑。

**v0.8.5 · 首个正式版 · Windows x64**

[下载安装包](https://github.com/HunterAyi/Aly-Canvas/releases/download/v0.8.5/AlyCanvas-0.8.5-Windows-x64-Setup.exe) · [本版说明](https://github.com/HunterAyi/Aly-Canvas/releases/tag/v0.8.5) · [软件主页](https://www.aly18.com)

## 可以做什么

- 用工程和编组整理素材，把文字、图片或整组素材连接到创作框作为参考。
- 配置自己的图片与视频API，拉取模型，查看模型支持的参考方式；支持GIF的模型可选择GIF创作。
- 裁剪、标注和本地抠图，配合在线模型做扩图，再用多轨整理音视频片段。
- 让小A协助理解接口资料、设置连接和处理画布工作；在线能力需要自行配置可用服务。

## 第一次使用

1. 下载并打开 `AlyCanvas-0.8.5-Windows-x64-Setup.exe`，选择安装位置。安装器会显示当前步骤、下载进度和速度。
2. 基础组件约 **738 MiB**。本地抠图模型和CPU环境约 **1.77 GiB**，首次使用相关功能时确认安装；已有兼容组件会复用。
3. 从首页新建画布。在API设置中填写自己的KEY，再拉取模型。Aly.AI是固定入口，也可以添加其他供应商。

无需预装系统Python或CUDA；已有的系统环境不作为必需依赖。在线模型服务可能收费，费用由用户与服务商确认，安装包不包含个人KEY。

关闭网页后软件仍在系统托盘运行，点击托盘或原启动器可恢复；从托盘菜单退出，才会正常结束后台程序。

## 更新和资料

有新版时，首页和API版本号旁会出现绿色提醒。先查看说明和本次大小，点击后才下载；保存工程、处理活动任务后再退出安装。更新在原位置替换程序，保留工程、素材、KEY、设置、小A会话和个人知识。

本版修复API首次进入、已选外观继承、多轨末尾空格重播及新版检查。本次旧版升级仅下载核心，约 **317.7 MiB**；兼容模型与环境继续使用。0.8.5的下载附件齐全，首次安装无需再找旧发布。
